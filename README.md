# Учебный проект iOS

Добро пожаловать в мой репозиторий! 🎉  
Этот проект создан для практики работы с Swift и Xcode.  
Здесь я учусь создавать приложения, настраивать проект и работать с GitHub.

## Что умеет приложение
- Показывает главный экран с приветствием  
- Работает с кнопками и текстом  
- Подключает учебные сервисы (например, Food Network Service, Drink Network Service)  
- Позволяет переходить между экранами
